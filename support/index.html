收藏與播放

可以收藏哪些內容？

支援 Instagram、YouTube、TikTok、Facebook 的影片連結，以及 Threads、X 貼文。可從來源 App 分享至拾片，或在拾片貼上連結；也能匯入你明確選取的本機影片。

拾片保存平台來源連結，不代為下載社群影片，也不掃描或抓取社群帳號收藏。

如何檢查可能失效的連結？

在「我的 → 拾片 Pro → 失效連結檢查」查看結果。需已同意連線及 Pro，固定每週自動分批輪查全部非私密平台收藏；不包含本機影片與私密分類。系統決定背景時機，開啟 App 時會補查，也可按「立即檢查全部」。關閉隱私與連線中的「連結資訊與封面」可停止後續連線。

「可連線」不保證影片可播放；「可能失效」表示來源回應 404 或 410，仍可能是平台限制；登入、限流或不支援檢查時顯示「無法確認」。結果及上次檢查時間保存在手機，重開仍可查看。只有新增疑似失效才發本機通知，未允許通知也會保存結果；不會自動刪除或修改收藏。

收藏無法播放，或沒有出現封面？

先確認網路及「我的 → 隱私與連線」設定。來源影片被刪除、設為私人、限制地區或不允許嵌入時，拾片不一定能播放或取得封面，可改按「在來源平台觀看」。

官方播放器可能要求你按一下播放，也可能顯示平台廣告或推薦。播放與封面失敗不會自動刪除收藏；回報時提供平台名稱、操作與錯誤即可，不必提供私人連結。

可以完全不連線使用嗎？

可以。第一次開啟可選「只用離線功能」，之後也能在「我的 → 隱私與連線」關閉連線功能。分類、筆記、手動備份與已匯入的本機影片仍可使用；平台影片、標題查詢與自動封面需要來源平台連線。

備份與還原

如何備份收藏？備份包含影片嗎？

在「我的 → 備份與還原」提供「完整備份（含影片）」與 JSON，手動備份與還原維持免費。只有 JSON 選項的舊版不會保存影片內容。

完整備份的 .clipnest 檔含收藏資料、仍存在的本機影片、本機影片封面及自選封面；平台下載縮圖不打包，還原後依連線設定重新取得。影片在裝置壓縮備份副本，以 720p 為目標、保留比例與聲音，不放大小尺寸影片；壓縮失敗或變大時沿用原片，App 內原片不改。還原壓縮副本可能降低畫質。

兩種備份都未加密。JSON 含收藏連結、筆記與分類，不含本機影片檔及封面；完整備份也無法補回備份前已遺失的影片，缺少影片時會提示失敗。備份後請確認成功並保管檔案，另外保留原始影片，不要公開分享備份。

還原會清空目前的收藏嗎？

目前還原會合併收藏。選取 .clipnest 或 JSON 後，依畫面選擇「合併，保留現有重複收藏」或「合併，以備份取代重複收藏」；取代只針對相同識別的重複收藏，其他收藏保留。

還原前先備份目前資料，並核對即將匯入的檔案。不要為了測試而清空收藏或解除安裝。完整備份可還原其中保存的影片副本；若只有 JSON，缺少的本機影片仍需重新匯入原始影片。恢復 Pro 不等於還原收藏。

自動備份為什麼沒有每天出現？

自動備份須先開啟並選取資料夾；在主 App 開啟或返回、且到了設定週期時才執行。沒打開拾片的日子不會在背景自動備份，也不是每天午夜固定執行。

設定「每天」時，距上次成功備份約 23 小時後可觸發。使用的是上次成功時間，剛按過「立即備份」會重新計時。每週、每月亦依所選週期檢查。

自動備份需有 Pro，並確認所選格式：舊設定可能仍是 JSON，新版可開啟「完整備份（含影片）」。完整備份使用不同時間戳檔名，不覆寫前份；JSON 同日仍更新當天檔案。只保留最近五份符合拾片自動備份命名的一般檔案，需長期保存的版本請另存，手動完整備份不被自動清理。

壓縮時請保持 App 開啟。若失敗，確認儲存空間及資料夾可用性，必要時重新選取資料夾；不要解除安裝處理備份問題。

本機影片

匯入後原始影片會被移走嗎？

不會。拾片只複製你選取的影片到 App 內，會占用額外儲存空間。刪除本機影片收藏會移除 App 內副本，原始檔不受影響。

解除安裝可能使 App 內資料與影片副本遺失。請保留原始影片，並在換機或解除安裝前自行備份收藏。

iPhone 從照片匯入失敗怎麼辦？

先確認儲存空間及影片能在系統中播放。可先將自己有權使用的影片存到「檔案」，再於拾片的「匯入本機影片」選「從檔案選影片」重試。若仍失敗，回報檔案格式、大小與畫面訊息即可，不需要寄送影片。

私密分類

私密分類是否加密？能禁止截圖嗎？

私密分類使用裝置生物辨識或螢幕鎖保護入口，屬於隱藏而非加密。拾片不會取得你的指紋、臉部或裝置密碼。

iPhone 會在切背景時遮蓋私密預覽，但無法禁止系統截圖；Android 的系統保護行為不同。完整備份及 JSON 都未加密，自動備份預設不包含私密分類。

Pro 與購買

月訂閱如何改為買斷？

先按「管理或取消訂閱」，自行在Apple或Google Play停止續訂；返回後按「重新確認續訂狀態」，確認後再主動按買斷。關閉管理視窗不代表已取消，也不會自動付款。

無法確認、仍續訂或有待處理／暫停購買時不開始付款。當期Pro仍保留，不自動退款、折抵或恢復續訂；不需要拾片帳號，也不將購買憑證傳給開發者。實際扣款與權益依商店結果。

已購買後，如何恢復或取消訂閱？

可使用購買時的同一個商店帳號，在拾片 Pro 頁選「恢復購買」。iPhone 使用 App Store、Android 使用 Google Play；權益不自動跨平台共用。

月訂閱由對應商店管理，請到商店的訂閱設定取消；解除安裝不會取消訂閱，取消後通常可用至當期結束。退款由對應商店依其規則處理。

恢復失敗時先確認商店帳號及連線，再重試。請勿為恢復權益而清除 App 資料或解除安裝，以免遺失本機收藏與影片。
